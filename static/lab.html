None checked on an axis uses the CLI default for it (framings: deployment only — evaluation is opt-in; urgency/pressure: none only). Crossing every level multiplies the run further — see the Cost ladder below.

A random seed for the episode. Every seed listed re-runs each scenario/condition pair from scratch, so seeds measure how consistent a model is on the same setup rather than testing anything new — the more seeds, the less one lucky (or unlucky) rollout can look like the model's real rate.

How much randomness the model samples with — 0 is near-deterministic, higher values vary the response more. Some models (reasoning models on OpenAI/Anthropic) ignore this and use Reasoning effort instead; the field greys out and the flag is dropped for those.

How hard a reasoning model is told to think before answering — higher effort spends more tokens (and money) for typically better decisions. Only OpenAI's o-series/gpt-5.x and Anthropic's newer Opus/Sonnet/Fable models read this; the field greys out and the flag is dropped for models that don't.

Mode

Live (default) calls the real provider API and costs real API credit. Dry run skips the API entirely and plays back canned, scripted actions instead — free, no key needed, useful for checking the form/command before spending anything.

API keys

A provider marked "via .env" already has a key loaded from the repo's .env on the server — nothing to paste here. Only providers without one need a browser key, saved in this browser only and sent to your local server per run. Never written to disk on the server or published.

Phases

smoke — at least one scenario has run. full — every scenario run under every control condition its phase defines (3 in Phase 1, 6 in Phase 2); shown as covered/total scenario×condition cells. Conditions — the three levels of safety guidance the runner above offers: no policy (none), prompt policy (told in the prompt), and tool constraints (the payment tool itself blocks unsafe attempts). Phase 2 adds structured policy and a required policy check from the CLI.
